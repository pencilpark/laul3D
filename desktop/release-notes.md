## Nouveautés

- Windows : les modèles « Plusieurs photos » retrouvent leurs couleurs dans l'aperçu Rendu. OpenMVS 2.4.0 noircissait les textures (issue OpenMVS #1257) ; l'app désactive l'étape en cause. Un modèle calculé avant cette version obtient ses couleurs avec « Recalculer avec ces réglages ».
- L'aperçu s'ouvre en mode Rendu dès qu'un modèle a des couleurs.
- Un projet se supprime depuis la liste des projets (corbeille, avec confirmation). Les fichiers déjà enregistrés dans Téléchargements restent.
- Des couleurs inexploitables (noires, texture illisible, faces sans photo) sont écartées, avec la raison dans le Journal technique.

## Installer

- Windows 10 ou 11, 64 bits : `Berria Craft_0.2.0_x64-setup.exe`. L'installeur n'est pas signé : SmartScreen demande une fois « Informations complémentaires » puis « Exécuter quand même ».
- Mac (puce Apple, macOS 14 ou plus récent) : `Berria Craft_0.2.0_aarch64.dmg`. L'app n'est pas notarisée : au premier lancement, l'autoriser dans Réglages Système > Confidentialité et sécurité > « Ouvrir quand même ».
